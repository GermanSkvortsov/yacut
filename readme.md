# YaCut

Сервис сокращения ссылок на Flask. Учебный проект, выполненный в рамках прохождения курса «Python-разработчик» в Яндекс Практикуме.

## Описание

YaCut — это веб-приложение для сокращения длинных ссылок. Пользователь вводит исходный URL и при желании предлагает свой вариант короткой ссылки. Если пользовательский вариант не указан, сервис генерирует уникальный короткий идентификатор автоматически.

Дополнительная функция — загрузка файлов на Яндекс Диск с автоматическим созданием коротких ссылок на скачивание.

## Функциональность

- Сокращение длинных ссылок

- Пользовательские короткие идентификаторы до 16 символов

- Автоматическая генерация уникальных коротких ссылок

- Переадресация на исходный URL

- REST API для создания и получения ссылок

- Асинхронная загрузка файлов на Яндекс Диск через aiohttp

- Обработка ошибок для веб-интерфейса и API

- Валидация пользовательских ссылок

## Технологии

- Python 3.12

- Flask

- SQLAlchemy

- SQLite

- aiohttp

- Pytest

## Установка и запуск

1. Клонируйте репозиторий:

bash " "git clone https://github.com/GermanSkvortsov/yacut.git " "

2. Создайте и активируйте виртуальное окружение:

bash " "python -m venv venv " "source venv/bin/activate " "

3. Установите зависимости:

bash " "pip install -r requirements.txt " "

4. Создайте файл .env с переменными окружения:

```bash
FLASK_APP=yacut
FLASK_ENV=development
SECRET_KEY=your_secret_key
DB=sqlite:///db.sqlite3 
```

5. Примените миграции:

```bash
flask db upgrade
```

6. Запустите проект:

```bash
flask run
```

Проект будет доступен по адресу: http://127.0.0.1:5000

## API

### Создание короткой ссылки

```bash
POST /api/id/
```

Тело запроса:

```json
{
  "url": "https://example.com",
  "custom_id": "my-link"
}
```

### Получение оригинальной ссылки

```bash
GET /api/id/my-link/
```
